## 🎯 Quick Start

### Your First Widget in 5 Minutes

**1. Open Elementor Editor**
```
Pages > Add New > Edit with Elementor
```

**2. Find Pagifye Widgets**
```
In Elements panel, scroll to "PAGIFYE" category
Or search: Type "navigation" or "hero"
```

**3. Add a Widget**
```
Drag & drop any widget onto your page
```

**4. Customize**
```
Click widget > Adjust settings in left panel
Content tab: Change text, images, links
Style tab: Customize colors, fonts, spacing
```

**5. Publish**
```
Click green "Publish" button
View your beautiful page!
```

## 📚 Widget Categories

### 🧭 Navigation Widgets (3)

Build professional navigation menus for your website.

#### Navigation-01
**Best for:** Main site navigation with full features

**Features:**
- Logo (image or text)
- Dropdown menus
- Desktop & mobile views
- CTA buttons
- Sticky option

**Use Case:**
```
Perfect for main header navigation on business sites,
landing pages, and multi-page websites.
```

**Configuration:**
1. **Logo Settings**
   - Upload logo image OR enter text logo
   - Set logo link (usually homepage)
   - Adjust logo size

2. **Menu Items**
   - Add menu items (unlimited)
   - Set menu text and links
   - Enable dropdown for submenu
   - Add dropdown items (format: Text|URL)

3. **Mobile Menu**
   - Automatically shows on tablets/phones
   - Separate mobile menu items
   - Custom hamburger icon

4. **CTA Buttons**
   - Add "Sign In" button
   - Add "Get Started" button
   - Customize text and links

5. **Styling**
   - Background color/gradient
   - Menu text colors
   - Button styles
   - Spacing and padding

#### Navigation-03
**Best for:** Modern rounded navigation design

**Unique Features:**
- Rounded container style
- Light/dark theme toggle
- Sleek, modern appearance

**When to use:**
```
Choose this when you want a more contemporary,
rounded design with theme switching capability.
```

#### Navigation-05
**Best for:** Classic horizontal navigation

**Features:**
- Clean, standard layout
- Logo and menu grouped together
- Simple, professional look

**When to use:**
```
Perfect for traditional business sites that need
a straightforward, professional navigation.
```

### 🦸 Hero Widgets (5)

Create stunning first impressions with hero sections.

#### Hero-01
**Best for:** Split-screen hero with image and content

**Features:**
- Heading with highlight text
- Description/subheading
- Multiple CTA buttons
- Hero image
- Image position (left/right)
- Background options

**How to use highlight text:**
```
Enter: "Welcome to {Our Platform}"
Result: "Our Platform" will be highlighted in different color
```

**Configuration:**
1. **Heading**
   - Enter main headline
   - Use {curly braces} for highlighted words
   - Choose HTML tag (H1, H2, etc.)

2. **Description**
   - Add supporting text
   - Keep it concise (1-2 sentences)

3. **CTA Buttons**
   - Add unlimited buttons using repeater
   - Set button text and link
   - Choose style (primary/secondary)
   - Add icons (optional)

4. **Hero Image**
   - Upload large, high-quality image
   - Recommended: 1200x800px or larger
   - Choose image position (left/right)

5. **Styling**
   - Background color
   - Text colors
   - Button colors
   - Spacing between elements

**Best Practices:**
- Keep headline under 10 words
- Description under 25 words
- Use 1-2 CTA buttons max
- High-resolution images
- Test on mobile devices

#### Hero-03
**Best for:** Full-width background with overlay

**Unique Features:**
- Full background image
- Gradient overlay
- Content positioned over image
- Rating stars (optional)

**When to use:**
```
Use when you have a stunning background image
and want dramatic impact. Great for SaaS, startups.
```

#### Hero-04, Hero-06, Hero-07
**Best for:** Various layout options

Each hero widget offers different layouts and features:
- Centered designs
- Different content arrangements
- Unique visual styles

**Choose based on:**
- Your design preference
- Content amount
- Brand style

### 💰 Pricing Widgets (3)

Display pricing plans beautifully.

#### Pricing-01
**Best for:** Pricing tables with billing toggle

**Features:**
- Monthly/annual toggle (Alpine.js)
- Multiple pricing cards
- Featured plan highlighting
- Feature lists
- Custom badges
- Responsive grid

**Configuration:**
1. **Section Heading**
   - Add main heading
   - Use highlight text if desired

2. **Billing Toggle**
   - Enable monthly/annual switch
   - Toggle works automatically with Alpine.js

3. **Pricing Cards** (Repeater)
   - Add 2-4 pricing plans
   - For each plan:
     * Plan name (e.g., "Professional")
     * Monthly price (e.g., "$29")
     * Annual price (e.g., "$290")
     * Features list (one per line)
     * CTA button text and link
     * Mark as featured (optional)
     * Badge text (e.g., "Most Popular")

4. **Grid Layout**
   - Choose columns (2, 3, or 4)
   - Automatically responsive
   - Mobile: stacks vertically

5. **Styling**
   - Card backgrounds
   - Featured card highlight
   - Badge positioning
   - Button styles

**Pro Tips:**
- Highlight your most popular plan
- Keep features comparable across plans
- Use annual toggle to show savings
- Test billing toggle on mobile

#### Pricing-02 & Pricing-05
**Alternative layouts** for different design needs

## 🎨 Styling Tips

### Color Schemes

**Choose colors that match your brand:**
```
1. Use brand colors consistently
2. Maintain good contrast (text/background)
3. Test on mobile devices
4. Consider accessibility (WCAG AA)
```

### Typography

**Create visual hierarchy:**
```
Headings: 32-48px
Subheadings: 20-28px
Body text: 16-18px
Small text: 14px
```

### Spacing

**Use consistent spacing:**
```
Section padding: 80-120px (desktop)
Element margin: 20-40px
Card padding: 30-40px
Button padding: 12px 32px
```

### Responsive Design

**Always test on:**
- Desktop (1920px, 1440px, 1280px)
- Tablet (1024px, 768px)
- Mobile (414px, 375px, 360px)

**Use Elementor's responsive controls:**
```
Click responsive icon in settings
Adjust per device
Hide elements if needed
```

## 🐛 Common Issues & Solutions

### Issue: Widget Not Displaying

**Solution:**
1. Clear Elementor cache
2. Regenerate CSS files
3. Check if widget is hidden on current device

### Issue: Styles Not Applying

**Solution:**
1. Clear all caches
2. Check for theme conflicts
3. Verify CSS specificity

### Issue: Alpine.js Not Working

**Solution:**
1. Check browser console for errors
2. Ensure Alpine.js loads
3. Test in different browser

### Issue: Mobile Layout Broken

**Solution:**
1. Check responsive settings
2. Test on real device
3. Adjust breakpoint settings

## 💡 Pro Tips

1. **Start with templates** - Create reusable page templates
2. **Use global colors** - Set up global color palette
3. **Save as template** - Save widget configurations for reuse
4. **Test thoroughly** - Always test on mobile before publishing
5. **Optimize images** - Compress images before uploading
6. **Use lazy loading** - Enable for better performance
7. **Minimize widgets** - Don't overload pages with too many widgets
8. **Keep it simple** - Less is often more in design
9. **Mobile first** - Design for mobile, enhance for desktop
10. **Get feedback** - Test with real users
