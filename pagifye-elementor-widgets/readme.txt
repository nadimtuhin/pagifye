== Installation ==

### Automatic Installation

1. Log in to your WordPress admin panel
2. Navigate to Plugins > Add New
3. Search for "Pagifye Elementor Widgets"
4. Click "Install Now" and then "Activate"

### Manual Installation

1. Download the plugin zip file
2. Log in to your WordPress admin panel
3. Navigate to Plugins > Add New > Upload Plugin
4. Choose the downloaded zip file and click "Install Now"
5. Activate the plugin

### After Installation

1. Make sure Elementor is installed and activated
2. Edit any page with Elementor
3. Look for the "Pagifye" category in the Elements panel
4. Start building beautiful pages!

== Frequently Asked Questions ==

= Do I need Elementor Pro? =

No, this plugin works with the free version of Elementor. However, it's fully compatible with Elementor Pro if you have it.

= Will this slow down my website? =

No! Our widgets are optimized for performance with efficient code and minimal asset loading. Assets are only loaded when widgets are actually used on a page.

= Can I customize the widgets? =

Absolutely! Every widget comes with extensive Elementor controls for customizing colors, typography, spacing, backgrounds, and more.

= Are the widgets mobile responsive? =

Yes! All widgets are fully responsive and look great on all devices - desktop, tablet, and mobile.

= Do the widgets work with my theme? =

Yes! Our widgets work with any WordPress theme that supports Elementor.

= Is the plugin accessible? =

Yes! All widgets follow WCAG 2.1 AA accessibility guidelines with proper ARIA attributes, keyboard navigation, and screen reader support.

= Can I use multiple widgets on the same page? =

Yes! You can use as many widgets as you need on a single page without any conflicts.

= What is Alpine.js? =

Alpine.js is a lightweight JavaScript framework used for interactive features like accordion menus, toggles, and mobile menus. It loads only when needed.

= Do you provide support? =

Yes! We provide support through the WordPress.org support forum and GitHub issues.

= Will you add more widgets? =

Yes! We're continuously working on new widgets and improvements. Stay tuned for updates!
