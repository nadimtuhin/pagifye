Transform beautiful Pagifye Tailwind CSS components into fully customizable Elementor widgets for WordPress.

== Description ==

Pagifye Elementor Widgets brings 34+ beautiful, pre-designed Tailwind CSS components to your Elementor page builder. Create stunning websites faster with professionally designed widgets across 11 categories.

= Features =

* 34+ fully customizable widgets
* 11 component categories
* Built with Tailwind CSS
* Interactive components with Alpine.js
* Full Elementor integration
* Responsive design out of the box
* Accessibility compliant (WCAG 2.1 AA)
* No coding required
* Regular updates

= Widget Categories =

* **Navigation** - Beautiful navigation bars and menus
* **Hero** - Stunning hero sections for landing pages
* **Pricing** - Professional pricing tables
* **Testimonials** - Customer testimonials and reviews
* **FAQ** - Accordion-style FAQ sections
* **Contact** - Contact forms and information
* **Content** - Content sections and layouts
* **Team** - Team member showcases
* **Blog** - Blog post layouts
* **Metrics** - Statistics and metrics display
* **Awards** - Awards and achievements

= Perfect For =

* Marketing agencies
* Freelance designers
* Business websites
* Portfolio sites
* Landing pages
* SaaS websites

= Requirements =

* WordPress 5.8 or higher
* Elementor 3.16 or higher
* PHP 7.4 or higher

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/pagifye-elementor-widgets`
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Make sure Elementor is installed and activated
4. Start using Pagifye widgets in Elementor editor

== Frequently Asked Questions ==

= Does this plugin require Elementor Pro? =

No, the free version of Elementor is sufficient. However, Elementor Pro features will enhance your experience.

= Are the widgets responsive? =

Yes, all widgets are fully responsive and work perfectly on mobile, tablet, and desktop devices.

= Can I customize the widgets? =

Absolutely! All widgets come with extensive customization options through Elementor's interface.

= Is this compatible with my theme? =

Yes, Pagifye Elementor Widgets works with any WordPress theme that supports Elementor.

= Do I need coding knowledge? =

No coding knowledge required. All customization is done through Elementor's visual interface.
